One word, deleted from the dictionary forever: **word**. The dictionary
erases the word for what it contains, and can no longer name a single
thing inside itself.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
